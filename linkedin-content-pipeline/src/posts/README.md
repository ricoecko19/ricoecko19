# Post records

One record per carousel: page content, caption, sources, and status.

Front matter carries `rotation_topic`, `pillar`, `status`, and the posting slot.
Design identifiers and live post URLs are account details and are not committed.

Read the most recent records before choosing a topic — see
[docs/how-to/add-a-content-source.md](../../docs/how-to/add-a-content-source.md).
